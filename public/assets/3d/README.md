# 3D store assets

Built from the supplied **ImageToStl.com_Untitled.zip** (Sketchfab "Super market low poly for free" by dasy444, Free Standard licence — keep the raw FBX bundle out of any redistributable asset pack).

Rebuild: `npm run assets3d -- /path/to/ImageToStl.com_Untitled.zip` (needs Python 3, numpy, Pillow).

| File | What |
|---|---|
| `fixtures.glb` | `shelf_bay`, `fridge_bay`, `freezer_chest`, `display_wall`, `checkout_counter`, `pos`, `cart_a`, `cart_b`, `sign_board` — metres, pivot at floor centre, length along +X, front +Z. Bays are cut to 3.25 m so one fits a 3.4 m game tile. |
| `products.glb` | 96 product-pack meshes (`pack_<id>`), each UV-mapped onto one cell of its department sheet and normalised to a 0.40 m longest edge. |
| `tex/*.jpg` | the supplied textures (ASCII names, resized) |
| `inventory.json` | all 250 meshes: role, usage (`used` / `partial` / `unused`), bounds, plus shelf-board anchors measured from the geometry |

## Things worth knowing about the source
* The FBX files contain **geometry only** — no UVs, no materials, no texture links. Roles were derived from shape, position and repeated-instance structure; UVs are generated by the build script (metric box projection for tiling surfaces, grid-cell mapping for product packs, whole-image mapping for the POS screen).
* Which product sheet goes on which pack mesh is **my assignment** (by pack proportions and the arrangement of the parked pack grid), not something recoverable from the files. Change `DEPT` in `scripts/build-store-assets.py` if a department looks wrong.
* The FBX files keep their original scene coordinates (a 28 m store), which is how repeated instances (5 gondolas, 5 wall fridges…) were recognised.
* There are **no people, floor, wall or decor models** in the bundle. Walls, floor, ceiling, people and small decor (plants, bench, vending…) are procedural in `components/game/Store3DScene.tsx`.
* Mesh 107 (78k triangles of wire baskets) is decimated by vertex clustering.

## Runtime
`components/game/Store3DScene.tsx` (three.js, loaded client-side only): angled orbit camera (drag = pan, pinch/wheel = zoom, two-finger twist or buttons = rotate), tile picking by raycast, instanced products/people/carts, DOM badges projected from world space.
